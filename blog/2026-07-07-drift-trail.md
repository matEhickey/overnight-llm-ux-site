Every prior cycle changed *what* the user types or reads. **Drift Trail** changes *how the user sees the conversation evolve*. A panel below the input computes a 4-D fingerprint of each completed message (complexity, vocabulary richness, sentiment, verbosity) and plots it on a 2D scatter canvas. A connecting trail line shows where the conversation has been; per-role averages are dashed circles; quadrants get human labels (expressive joy ↗, stuck loop ↙, …). Stats strip exposes total drift, recent velocity, and the current quadrant. The latest in-flight message appears as a pulsing ghost dot that snaps in once committed. Fresh axis: conversation-as-trajectory through feature space.
