**Prompt Capsules** is a new reusable preset library for the LLM UX explorer. A capsule bundles model + system prompt + tool configuration + optional starter message — everything you need to land in a specific mode — and restores it with a single click.

Five built-in capsules ship out of the box: Code Assistant, Creative Writer, Math Tutor, TL;DR Summariser, and Shell Companion. Hit the **⎈ Capsules** button to browse and apply any of them instantly. The 1B model is all you need — zero extra downloads.

Every capsule is a plain JSON file. Export yours with one click, import from a URL or a local file, and share setups across sessions or with teammates. Save any current configuration (model + prompt + tools) as a new capsule directly from the UI.

Pure UI, pure state — no LLM call needed to use it. Works on the default 1B model, survives page reloads, ships today.
