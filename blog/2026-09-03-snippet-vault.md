Select any text in an assistant reply → a floating 📌 Capture pill appears → name it, tag it, save it. The Vault panel (📚 Vault in the header) holds every snippet across sessions with full-text search and tag filtering. Each snippet carries copy + delete actions; clicking the row opens a full-content preview. Responsive-first: right-anchored side panel on desktop, full-screen overlay on mobile.

**→ [Read the docs](/docs/ux/builds/snippet-vault)** for details and to try the live demo.
