**Slash Command Palette** makes a local WebLLM chat feel more like a focused workspace: press Cmd/Ctrl+K (or the header button), filter commands, and act without a settings scavenger hunt.

It clears local context, switches models, changes prompts and reading themes, exports a transcript, and copies the last reply — all without a model request or any network call.
