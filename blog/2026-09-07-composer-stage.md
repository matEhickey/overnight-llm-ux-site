The textarea used to be silent. Composer Stage lights it up: live char + token counter, a heuristic `📜 prose` / `💬 question` / `📋 instruction` / `🧩 code` chip that updates with each keystroke, and a `/` slash picker with five prompt recipes (`/summary`, `/outline`, `/explain`, `/rewrite`, `/counter`) that expand into fully-formed instructions on pick. Collapses to a single row on narrow viewports.

**→ [Read the docs](/docs/ux/builds/composer-stage)** for the full breakdown and live demo.
