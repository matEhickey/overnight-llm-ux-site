Focus Lanes segments every assistant reply into a vertical stack of distinct lanes — Intro, Question, Answer, Code, List, Closing — each with its own color, label chip, and a jump-to anchor in a sticky mini-toc.
Pick a preset (Read all / Skip to answer / Code only), toggle per-kind collapse, and the layout reflows at every viewport via CSS container queries.
